# 🧪 CHEMISTRY EXPLORER (Class 11 JEE Edition)
**Made with ❤️‍🩹 by Aditya Maurya**

An interactive, HD-graphics Android application for Class 11 NCERT & JEE Chemistry featuring:
- **NotebookLM-Style 3D Flashcards** with Hindi definitions (`Teko` font), English key terms, and `KaTeX` equations.
- **15 Multi-Level Conceptual Games** (Starting with the 5-Level Modern Periodic Table Drag & Drop).
- **Interactive Lab, Calculators & Graph Visualizer**.
- **Zero Data Loss Updates** via persistent `localStorage` state management.
